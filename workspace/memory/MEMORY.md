# Long-term Memory

This file stores important information that should persist across sessions.

## Purpose

- **ONLY load in main session** (direct chats with your human)
- **DO NOT load in shared contexts** (group chats, sessions with other people)
- This is for **security** — contains personal context that shouldn't leak to strangers

## What to Capture

- Significant events and decisions
- User preferences and habits
- Important context about projects
- Lessons learned from interactions
- Opinions and perspectives you've formed
- Things to remember for future sessions

## Writing Guidelines

- Write distilled insights, not raw logs
- Update periodically (review daily notes and consolidate)
- Remove outdated information that's no longer relevant
- Be specific enough to be useful, not so detailed it's overwhelming

## Structure

### User Information
(Important facts about user)

### Preferences
(User preferences learned over time)

### Important Notes
(Things to remember)

### Project Context
(Active projects, current goals, blockers)

### Lessons Learned
(Insights from past interactions)
